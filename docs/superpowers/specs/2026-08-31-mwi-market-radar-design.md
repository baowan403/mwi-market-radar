# MWI Market Radar v1 設計規格

日期：2026-08-31  
狀態：Owner 已接受整體方案；本文件等待 Owner 最終審閱  
範圍：獨立市場看盤頁面 + Tampermonkey 本機採集器，不包含交易操作

## 1. 目標

建立一個類似股票看盤軟體的 Milky Way Idle 市場觀察工具。只要 MWI 遊戲頁保持開啟，Tampermonkey 就定時保存官方全市場快照；獨立看盤頁面則呈現 1D、3D、7D 漲跌、成交量、價差、異常訊號與自選名單。

正常採集與查看完全在瀏覽器本機執行，不呼叫 AI，因此不消耗 Codex／模型 tokens。工具只能讀取公開市場資料，不讀取帳號 cookie、token、角色資料、背包、聊天或訂單，也不送出任何買賣操作。

## 2. 已選方案

採用「公開靜態網站 + 單一 Tampermonkey 腳本 + 本機 GM 儲存」：

- 靜態網站只提供 HTML、CSS、JavaScript 介面，可部署到 GitHub Pages。
- 同一支 Tampermonkey 腳本同時匹配 MWI 遊戲頁及獨立看盤頁。
- 遊戲頁負責採集；看盤頁透過腳本橋接讀取本機歷史資料。
- 市場歷史只保存在使用者自己的 Tampermonkey 儲存空間，不上傳到 GitHub Pages 或第三方伺服器。
- 網址尚未決定。任何建立 repository、GitHub Pages 或公開網址的動作，都必須先向 Owner 確認確切網址／帳號／repository 名稱。

不選純 Windows 排程作為 v1，因為它在電腦關機時同樣會漏資料，且安裝與維護成本較高。未來可以讓排程器沿用相同資料格式作為可選補充。

## 3. 資料來源與採集節奏

主要來源：

`https://www.milkywayidle.com/game_data/marketplace.json`

每筆官方快照提供時間戳，以及各 `itemHrid + enhancementLevel` 的：

- `a`：最低賣價（ask）
- `b`：最高買價（bid）
- `p`：官方市場價格／均價欄位
- `v`：官方成交量欄位

採集規則：

1. MWI 頁面開啟後立即檢查一次。
2. 預設每小時 `xx:08` 檢查，避開官方常見約 `xx:06` 的快照更新時間。
3. 以官方 `timestamp` 去重；相同時間戳不重複寫入。
4. 取得舊時間戳或暫時失敗時，10 分鐘後只重試一次，之後等待下一輪。
5. 多個 MWI 分頁利用 leader lock，只允許一個分頁採集。
6. 電腦關機、瀏覽器關閉或沒有 MWI 分頁時不採集；缺口如實顯示，不插值、不偽造行情。

`p` 有效時作為主要趨勢價格；若無有效 `p`，才使用有效 ask/bid 的中間價。只有單邊報價時保留並標記為單邊；ask 與 bid 都為 `-1` 時標記「無市場」，不得算成 0 或製造虛假漲跌。

## 4. 分類與導覽

### 4.1 官方分類

資料層完整保留 MWI 現有十種 `categoryHrid`，不自行改寫物品歸屬：

1. 貨幣
2. 戰利品
3. 卷軸
4. 迷宮
5. 地下城鑰匙
6. 食物
7. 飲料
8. 技能書
9. 裝備
10. 資源

### 4.2 股票式檢視

主要導覽依序為：

- 自選
- 全市場
- 資源
- 消耗品
- 技能書
- 迷宮
- 裝備
- 其他

「消耗品」是食物、飲料、卷軸的合併捷徑；「其他」是貨幣、戰利品、地下城鑰匙的合併捷徑。頁面仍可展開並單獨選擇全部十個官方分類。這些只影響篩選，不更動原始分類。

裝備的不同強化等級必須視為不同市場標的，例如 `時空手套 +7` 與 `時空手套 +10` 分別計價、排序及釘選。

## 5. 自選名單

- 每個物品列與詳情頁都有釘選／取消釘選按鈕。
- 自選以 `itemHrid + enhancementLevel` 為唯一鍵。
- 可拖曳調整自選順序；排序模式啟用時暫時依選定欄位排序，切回「自訂順序」後恢復手動排列。
- 自選支援搜尋、分類篩選與 1D／3D／7D 切換。
- 自選資料與市場歷史一樣只存在本機。
- v1 不建立多個自選群組，避免提前增加管理複雜度。

## 6. 行情表與排序

行情表預設欄位：

- 自選星號
- 物品名稱與強化等級
- 官方分類
- 目前價格
- 買一／賣一
- 價差百分比
- 官方成交量
- 1D、3D、7D 漲跌幅
- 最後快照時間／資料品質標記

所有數值欄位均可點擊表頭切換：降冪、升冪、回到預設。至少支援：

- 漲幅最大／跌幅最大
- 價格高低
- 成交量高低
- 成交量異常程度
- 價差大小
- 波動率高低
- 名稱與官方分類

時間按鈕 `[1D] [3D] [7D]` 決定主要漲跌欄、排行榜與圖表窗口。比較基準採目標時間以前／附近最近的有效快照，並顯示實際間隔；資料不足時顯示「樣本不足」，不得拿較短期間冒充。

顏色依 Owner 習慣採台股語意：紅色上漲、綠色下跌、灰色持平／缺資料，同時顯示 ▲、▼、—，避免只靠顏色判讀。

## 7. 市場頁面

### 7.1 首頁摘要

- 最新官方快照時間
- 本機最後採集時間
- 下一次預計採集時間
- 採集狀態與漏失區間提醒
- 目前區間上漲／下跌／無資料標的數

### 7.2 自選

以緊湊股票報價表顯示 Owner 釘選標的。預設按照手動順序，可切換漲跌幅、成交量、價差等排序。

### 7.3 全市場排行榜

- 漲幅榜
- 跌幅榜
- 成交量榜
- 成交量異常榜
- 波動榜
- 大價差榜
- 無買單／無賣單

共同篩選器：官方分類、強化等級、最低成交量、最大價差、關鍵字。篩選後的排序只作用於目前結果。

### 7.4 單品詳情

- `p`、ask、bid 時間序列折線
- 成交量柱狀圖
- 1D／3D／7D 漲跌與區間高低
- 實際快照數、缺口、單邊報價警示
- 釘選按鈕

圖表不得把缺失價格連成看似連續的走勢。

## 8. 異常與流動性訊號

v1 的提示是篩選工具，不宣稱為買賣建議：

- 1D 絕對漲跌至少 5%
- 成交量至少為過去 7 日同時段中位數的 2 倍
- 買賣價差至少 10%
- 單邊市場、低樣本或成交量過薄

所有門檻放在本機設定中可調整。低流動性商品即使漲幅很高，也必須同時帶有「薄量」標記，避免把不可實現標價誤認為機會。

## 9. 儲存與保留

- 最近 8 日：保留逐小時全市場快照。
- v1 超過 8 日即移除最舊逐時分塊；8 日足以支援完整 7D 比較並保留緩衝。
- 採日期分塊的壓縮儲存，避免單一 GM key 無限膨脹。
- 自選設定、顯示偏好與異常門檻獨立儲存。
- v1.1 再加入每日 open/high/low/close 彙整（最多保留 1 年）、JSON 匯出／匯入與容量管理；v1 必須保證瀏覽器重開後仍可讀取。

## 10. 隱私與安全邊界

允許：

- 唯讀下載官方 `marketplace.json`
- 保存市場公開欄位
- 在獨立頁面顯示、排序、篩選與繪圖

禁止：

- 讀取或保存 cookie、token、帳密、localStorage 角色資料
- 讀取背包、角色、聊天、好友、訂單或其他私人狀態
- 自動下單、成交、取消訂單或操作遊戲市場
- 把本機市場歷史上傳到 GitHub Pages 或未經 Owner 同意的服務

## 11. 錯誤處理

- 官方端點失敗：保留舊資料、顯示失敗時間、按規則重試一次。
- JSON schema 異常：拒絕寫入該快照，避免污染歷史。
- 儲存空間不足：先停止寫入並提示匯出／整理，不靜默刪除自選。
- 看盤頁未安裝腳本：顯示明確安裝說明，不顯示假示範行情。
- 時區統一內存 UTC、畫面顯示 Asia/Taipei；跨日比較依時間長度而非日曆日期。

## 12. v1 驗收標準

1. 開著 MWI 時，每小時可自動保存一個新的官方時間戳。
2. 多個 MWI 分頁不會重複採集。
3. 瀏覽器重開後歷史與自選仍存在。
4. 1D／3D／7D 使用正確且可追溯的比較快照。
5. `-1`、缺資料及單邊報價不產生假漲跌。
6. 不同強化等級分開顯示、排序與釘選。
7. 十個官方分類及合併捷徑篩選正確。
8. 自選可釘選、取消、手動排序及按行情欄位排序。
9. 全市場可依漲跌、成交量、價差、波動排序並交叉篩選。
10. 單品圖表正確呈現缺口，不做虛假插值。
11. 看盤頁沒有腳本時能說明缺少橋接，而非顯示空白或假資料。
12. 正常採集與看盤過程不發出任何 AI 請求，AI token 消耗為零。

## 13. 版本邊界

- v1：採集器、自選、官方分類、1D／3D／7D、排行榜、篩選、單品圖表。
- v1.1：匯出／匯入、每日彙整、儲存容量管理。
- v1.2：本機桌面／瀏覽器提醒。
- v2：在授權與用量邊界明確後，可選 mooket 歷史補洞。
- v2.1：可選 Windows 排程採集器，沿用同一資料格式。
- v3：可選 Milkonomy 收益交叉檢查；仍不自動交易。

## 14. 部署裁決點

實作可先用本機頁面驗證，不需要網址。準備部署時，必須先詢問 Owner 並確認：

1. 使用哪個 GitHub 帳號／組織。
2. repository 名稱。
3. 希望的 GitHub Pages 網址或是否使用自訂網域。
4. repository 要公開或私人（需確認 Pages 方案支援狀態）。

未取得上述確認前，不建立遠端 repository、不發布網址、不聲稱網站已上線。
