# 移除突發短缺／暴利模式

## 決策

移除策略頁的「⚡ 突發短缺／暴利」按鈕、技能下拉選項與專用全量掃描。一般策略榜已按玩家選定的掛機時間計算可實現收益，並顯示 1D／3D／7D、72H 動能、產量占比、風險與優先級；低絕對收益但短期百分比暴漲的候選不值得用一個會卡住頁面的獨立入口呈現。

## 保留

- 策略推薦、機會雷達、升級目標。
- 0.5H／1H／6H／12H／24H與自訂時長。
- 一般榜的動能、趨勢、風險及優先級。
- 固定12欄與既有收益公式。

## 驗收

- 工具列與技能選單不再出現「突發短缺／暴利」。
- 切換所有掛機時間仍能正常排序並顯示策略。
- 不再為了特殊模式同步計算全部候選的歷史序列與回測。
