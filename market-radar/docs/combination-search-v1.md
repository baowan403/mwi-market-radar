# 跨技能組合搜尋第一版

## 已實作

主策略榜加入跨技能2／3步和三個動作內的雙產物分流。保留原本製造長鏈（最多7步）及單步候選。例：製造→分解、轉化→分解、分解→製造→分解；是否有利完全由當下價格決定。

每個動作沿用角色配裝、茶飲政策與催化劑選擇結果。依上游產量與下游消耗比例分配工時，所有 workFraction 合計1；先抵消中間材料才計成本與售出收入。分流不把兩條支線當成同時掛機；外部補料、Coin成本、茶與所有副產物仍計EV。

價格缺失不會變成0：可從物理ledger恢復中間材料數量，但整鏈最後仍需要所有外部買入與出售項目有價格。未知物品、循環、同一份產出重複配置都拒絕。轉化基本模型已扣除自身返還，不再次算出售。

多個最終主產物使用「衍生清算」，逐一檢查售出容量／無買單，不能藏在Coin免出售或稀有副產物警告之後。風險保留最嚴格一端；實際可執行工時取最小值。

## 明確限制（不是全球最優解宣稱）

- 全市場直接窮舉在壓力測試耗盡4GB記憶體，未發布該版本。
- 本版每個起始動作最多評估120次連接、保留8個正理論收益候選；主榜再按原有容量／時長估算排序。此預篩有遺漏其他可行或高容量路線的可能，畫面有「非完整窮舉」提示。
- 最多3個新增動作，不是任意深度的完整MK超級煉金；稀有／箱子維持終端EV，未再向下加工。非主產物偶然掉落不擴展成新支線。
- 沿用每步茶飲政策，未窮舉整鏈聯合配茶或配裝。沒有把本輪高日利冒充固定長期保證。
- 升級目標仍用原有單技能路線比較，不在每件裝備上重跑深度搜尋；已在該頁標示。存錢參考仍取主榜最高24H預估收益。
