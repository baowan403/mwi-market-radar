Approved by Owner: fast shortlist, profit/XP modes, top-three reference average, real quoted enhancement grades, slot summaries, retain savings/ownership/market checks.

Quick evaluation scans the selected skill once, picks 1/3/5 distinct profitable reference routes (default3), then recalculates only those routes per gear using existing calculators and tea policy. Profit uses session returns with capacity. XP divides selected-skill XP earned during executable hours by planned hours, using the same tea policy; it is not a target-level forecast or a joint XP tea optimizer. Do not choose huge-loss XP farms as reference routes.

Explicit verification takes at most6 shortlist leaders (gain and efficiency), searches all skills/cross-skill combinations touching the selected skill, compares against a separately recalculated full baseline, and labels its results. Never mixes quick deltas with a verified denominator.

Observed positive asks determine enhancement levels; unquoted +0 retained in a pending list. No wallet gating. Exact owned and lower grades excluded. Unknown eligibility/quotes do not qualify for shortlist leaders.

UI: profit/XP selector, reference count, per-slot leaders by default, expand all/pending, explicit verify button. Existing nine-column upgrade layout and main12-column strategy table retained. XP columns show XP/h, incremental XP/h per1M, no monetary payback for XP itself. Savings remains full price / all-skill best24h profit.
