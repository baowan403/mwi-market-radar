# 裝備比較：快速初選、精算與經驗

2026-09-08，取代每件裝備都重新掃描全技能的升級比較。

- 快速比較：先掃一次所選技能，取可執行收益最高的1／3／5條不同路線（預設3），每件裝備只複算這些固定參考路線；比較的是平均增益。
- 賺錢／衝等共用高收益參考路線，避免直接選到巨額虧損的最高XP項目。衝等列出XP/h提升與每1M投資的XP/h增益，保留實際金錢變化在展開明細。
- XP/h = 所選技能工作XP/h × 可執行工時 / 所選工時；因此與市場容量、掛機時長一致。沿用當前手動／自動配茶政策，尚未做XP目標配茶與目標等級時間預測。
- 精算前6項：初選增益前三＋CP前三的聯集，最多6件；重算完整基準與這些裝備，納入主榜候選範圍內、涉及所選技能的跨技能組合。精算結果不沿用快速平均基準。
- 強化等級取目前有正Ask的實際市場等級，另保留無報價+0供待確認。已持有或已裝備的同級／低級不重買。
- 預設每部位顯示增益與CP代表；可展開全部及待確認。未知門檻／價格不當作最佳推薦，不讀錢包。存錢天數仍為完整購入價除全技能最高24H預估收益。
