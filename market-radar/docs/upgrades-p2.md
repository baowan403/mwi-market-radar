# P2 升級目標榜

不讀取餘額、不按購買能力過濾。以所選生活技能與每日使用時數比較市場裝備+0/+5/+7/+10。

- 比較上衣、下衣、工具及共用裝備；沿用真實收益與5%容量參考模型，重新枚舉所選技能的單步／同技能多步路線，不把屬性加權當CP值。跨技能流程本版不納入。
- 基準先解析目前配裝，之後鎖定其他裝備；只換一件。茶保持相同手動／自動政策，兩邊公平重算。共用装不加總九技能收益。
- 價格按對應強化等級Ask；無報價保留但不冒充免費。已明確持有同強化等級者標示免購買。
- 未達裝備門檻仍保留目標與價格，但不顯示目前可用收益；資料不足的門檻標示待確認，效果僅作假設可穿的情境。
- 日增益=換裝後最佳容量限制收益−原配置最佳收益；回本=完整購買價/日增益，不默認賣掉舊裝或合計多件增益。
- 提供提升最大／投資效率排序；同物品不同強化等級列出直接購買差價與額外增益，不冒充分階買賣已最優。
- 本版不做自行強化EV、房屋、公會神龕、訓練成本或預算配置。存錢和預备金由玩家決定。

實作：candidates.ts增加可選單技能範圍，默认行為不變；upgrades.ts枚舉／情境重算／結果；upgrade-view.ts獨立頁面，點分析才計算，可取消並顯示進度。相同Buff情境共用計算，不改真實角色。
